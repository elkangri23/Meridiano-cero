Estado: diseño documentado; todavía no existe aplicación instalable. Los comandos de producto aquí descritos son objetivos de la implementación, no procedimientos probados. El único comando ejecutable incluido actualmente es la verificación documental.

- [Uso del juego](USO.md): experiencia y herramientas que implementaremos.
- [Desarrollo](DESARROLLO.md): entorno, arquitectura y flujo de contribución.
- [Instalación](INSTALACION.md): arranque local y autoalojamiento previstos.
- [Operación](OPERACION.md): actualización, backups, incidentes y diagnóstico.
- [Pruebas y calidad](PRUEBAS.md): qué demostrar antes de cada entrega.

Para requisitos normativos usar las specs; para secuencia de ejecución usar roadmap/backlog. Estos manuales explican el uso previsto y se convertirán en guías verificadas con evidencias en fases 1, 3 y 6.
