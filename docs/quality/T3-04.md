Evaluar cuando se elijan servidor/modelo, registrar compatibilidad y contexto efectivo, repetir sobre el caso fijo y demostrar ambas rutas. HTTP de partidas y guardado transaccional dependen de T3-02/T3-03.

## Continuación del mismo worktree

Se corrigen dos problemas encontrados al revisar el primer avance: el codec podía aceptar un acto que se convirtiera a texto, y el respaldo podía elegir un acto no permitido. Ahora se valida sin coerciones, se exige coherencia acto/hechos y se respeta el conjunto autorizado, incluido silencio. Cuando no existe acto válido se usa un resultado operativo sin memoria nueva.

Se validan memorias al entrar a converse, ofertas de acción con IDs únicos y cancelaciones antes/después del proveedor. Si un error coincide con la cancelación se prioriza esta; una respuesta tardía no propone acciones ni escribe memoria. La narración conserva los hechos confirmados.

El corpus versión 2 añade memoria restaurada, referencia contextual y revocación de permisos. También se prueba el propio evaluador: un proveedor caído o uno que pide aclaración para todas las órdenes no aprueba. Se añade el paso determinista al workflow; no se ha ejecutado GitHub Actions ni se ha cambiado el bloqueo global heredado de T2.
