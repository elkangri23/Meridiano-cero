# ADR-009 Versionado e intercambio

Estado: aceptado como decisión de implementación del plan. Fecha: 2026-10-27.
Trazabilidad: SPEC-002; REQ-G17-01; E4-01; ACC-023.

## Contexto

Compartir casos entre proveedores sin alterar partidas activas.

## Decisión

JSON declarativo versionado, validación dura, hash canónico y exportación explícita con aviso de solución.

## Alternativas

Código/script importable compromete el servidor; ofuscar solución no aporta confidencialidad real.

## Consecuencias y revisión

Hash no firma autoría. Versiones futuras se rechazan. Limitar tamaño/profundidad en SPEC-007 y no importar URLs de assets arbitrarios.
