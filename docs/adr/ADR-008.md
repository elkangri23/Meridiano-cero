# ADR-008 Web y despliegue

Estado: aceptado como decisión de implementación del plan. Fecha: 2026-10-27.
Trazabilidad: SPEC-009; REQ-T07; E6-01; ACC-032.

## Contexto

Instalaciones independientes y uso público gratuito con una misma base.

## Decisión

Web responsiva sin PWA obligatoria. Compose; IA local permitida por configuración de administrador; público usa IA de servidor.

## Alternativas

Apps nativas/offline integral fuera de v1; servicio central obligatorio contradice autoalojamiento.

## Consecuencias y revisión

Modo local no puede activar bypass en público. Ollama fuera de Docker inicialmente, dirección configurable.
