# Glosario del dominio

| Término | Significado |
|---|---|
| Expediente / CaseDefinition | Toda la investigación fijada antes de jugar, incluidos secretos |
| Partida / CaseRun | Ejecución de un detective sobre un expediente |
| PlayerView | Solo estado y hechos autorizados para el jugador |
| Hecho | Afirmación fijada por la definición; no improvisada por la IA |
| Evidencia | Objeto, observación, testimonio, análisis o registro con procedencia |
| Admisibilidad | Si una prueba puede contribuir a una orden según reglas ficticias |
| Corroboración | Relación sustentada entre evidencias, sin juicio de culpabilidad automático |
| NPC | Personaje con conocimiento y condiciones de comunicación limitados |
| Motor | Reglas deterministas que modifican estado y reloj |
| Intérprete | IA que traduce texto en intención estructurada, sin ejecutarla |
| Narrador | Redacción limitada a eventos y hechos autorizados |
| Generador | Pipeline que prepara un expediente completo |
| Validador duro | Comprobaciones deterministas que no puede anular una IA |
| Revisor semántico | Evaluación de plausibilidad/coherencia/tono, complementaria |
| Simulador | Ejecuta rutas y casos de error para comprobar solvencia |
| Ruta independiente | Camino de resolución que no necesita las pruebas decisivas del otro |
| Reloj interno | Minutos de juego que avanzan por acciones, no por tiempo de pared |
| Job operativo | Trabajo de generación que usa reloj real y cola persistente |
| Solicitud de juego | Análisis/gestión con vencimiento en minutos internos |
| Preview | Estimación y plan que todavía no aplica efectos |
| Idempotencia | Repetir una solicitud identificada no repite sus efectos |
| Semilla | Entrada persistida para aleatoriedad reproducible |
| Dossier | Vista de información ya obtenida por el detective |
| Orden | Suficiencia ficticia para detener/acceder, no sentencia de culpabilidad |
| Hito | Entregable demostrable con pruebas y revisión |
| Spec | Contrato de comportamiento e interfaces |
| ADR | Registro del porqué de una decisión de arquitectura |
| Evidencia de entrega | Resultado real de comprobación, distinto de evidencia detectivesca |
| Autoalojamiento | Instalación independiente con proveedor propio |
| Familiar / General | Restricciones de contenido verificadas en generación y narración |
